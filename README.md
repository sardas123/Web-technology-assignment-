# Web-technology-assignment-
Resume and Bio-data Website

A simple multi-page personal website built as a college assignment. It has a Home page, a Resume page, a Bio-data page and a Contact page, all inside a single file: index.html.

Live site: https://your-username.github.io/my-resume/

Pages
Page	What it shows
Home	Photo, short introduction and buttons to the other pages
Resume	Objective, education table, skill bars, projects and achievements
Bio-data	Personal details table and declaration
Contact	Contact form with simple validation
Technologies Used
HTML5 for the structure (header, nav, main, sections, tables, lists, form)
CSS3 for styling (CSS variables, flexbox, grid, responsive layout)
JavaScript and jQuery for interactivity:
Switching between pages when a menu link is clicked
Animated skill bars
Contact form validation (name, email format and message)

my-resume/

How to Run Locally
Download or clone this repository.
Double-click index.html to open it in any web browser.

An internet connection is needed because jQuery is loaded from a CDN (cdnjs.cloudflare.com).

How to Customise
Open index.html in a text editor such as VS Code or Notepad.
Replace "Your Name", the email, phone number, address, education, skills and projects with your own details.
To add your photo, save it in the same folder (for example photo.jpg) and change the image line to <img src="photo.jpg" alt="Profile photo">.
How to Host on GitHub Pages
Create a public repository on GitHub.
Upload index.html (and your photo, if any).
Go to Settings → Pages.
Under Branch, choose main and / (root), then click Save.
After 1 to 2 minutes, your site is live at https://your-username.github.io/repository-name/.
